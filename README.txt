C DRIVE CLEANER

QUICK WINDOWS TEMP CLEANUP
Click Clean Windows Temp in either window, then choose Yes in the Windows
administrator prompt. The app removes Windows temporary files older than
7 days, skips locked files, and reports reclaimed space. No folder selection
is needed. The Temp folder and newer files are preserved.

Double-click Start Cleaner.vbs. No installation or downloads required.
The Storage Map opens with the last saved AppData scan, when available.
Saved scans show their date and time. Click Analyze to refresh after cleanup
or other disk changes. The first opening scans AppData in the background.
Revisiting an analyzed folder reuses its saved results. Large folders show
their top 500 entries to keep the window responsive; all entries count in totals.
Choose C:\ for the whole drive, or type any folder on C:, then Analyze.
The chart and sorted list show each folder's share of measured data.
Double-click a folder to drill down; Up returns to its parent.
The largest-files list reveals a file in Explorer when double-clicked.
Stop ends a scan and retains partial results.
Safe cleanup opens the cleanup window: click Scan, check categories,
then Clean selected. Notion, Codex and DropboxElectron caches are included.
Use Run as administrator only if you want to inspect protected temporary folders.

Scans old user/Windows temporary files, reaConverter temporary files, crash
reports, and Chrome/Edge/Brave caches. It does not delete personal documents,
browser passwords/history, Google Drive data, Recycle Bin contents, installed
programs, recovery data, or Windows servicing files.

Temporary files must be at least 7 days old; browser cache files 1 day old.
Close affected applications before cleaning. Deletion is permanent.
Locked files are skipped. Directory links are never followed. Sizes are
logical file sizes; actual disk space reclaimed may differ. Hard-linked files
can be counted more than once. Protected folders can be inaccessible, and
cloud/linked folders are skipped. Folder shares are of measured data, not
the drive's exact physical usage. The top capacity meter uses Windows totals.

The app deliberately does not claim every hidden file is useless. Large
system files and other unrecognized folders require separate investigation.
